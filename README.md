# 🖥️ Rediseño Web Software Colombia - Análisis y Mejora de UX/UI

## 📌 Descripción

Este proyecto consiste en el **análisis y rediseño parcial** del sitio web de una empresa real, con el objetivo de identificar problemas de usabilidad, estructura y experiencia de usuario, y proponer una solución más clara e intuitiva.

El trabajo se centró en la página de **Software Colombia**, sobre la cual se realizó una reestructuración de secciones clave, manteniendo como base tecnologías web nativas: **HTML, CSS y JavaScript**.

---

## 🎯 Objetivo del proyecto

- Analizar una página web existente desde la perspectiva de UX/UI.
- Detectar problemas en la organización de la información.
- Proponer e implementar mejoras en la experiencia del usuario.
- Aplicar buenas prácticas en desarrollo web con tecnologías básicas.

---

## 🔍 Problemas identificados

Durante el análisis del sitio original, se detectaron los siguientes puntos críticos:

- ❌ **Saturación de información** en secciones clave.
- ❌ **Falta de claridad** en la presentación de productos y servicios.
- ❌ **Dificultad para entender la oferta** de la empresa.
- ❌ Estructura poco intuitiva para el usuario.

Estos factores podían generar confusión en los usuarios al momento de explorar o solicitar servicios.

---

## 🚀 Solución propuesta

Se desarrolló una versión mejorada del sitio enfocada en:

- ✅ Simplificación del contenido.
- ✅ Mejor organización de la información.
- ✅ Jerarquización visual más clara.
- ✅ Navegación más intuitiva.
- ✅ Reducción de la carga cognitiva del usuario.

---

## 🧩 Alcance del rediseño

Las mejoras se aplicaron únicamente a las siguientes secciones:

- 🏠 **Index (Página principal)**
- 📦 **Productos**
- 🛠️ **Servicios**

Las demás secciones no fueron modificadas. En su lugar, se implementó un sistema de navegación que redirige al sitio original para mantener la coherencia de la experiencia.

---

## 🛠️ Tecnologías utilizadas

- **HTML5** – Estructura del contenido  
- **CSS3** – Estilos y diseño visual  
- **JavaScript (Vanilla)** – Interactividad y navegación  


---

## ⚙️ Características técnicas

- Reorganización del contenido basada en principios de UX.
- Implementación de navegación híbrida (local + redirecciones).
- Diseño enfocado en claridad y usabilidad.
- Uso de JavaScript para control de navegación.
